Die Normierungen sind hier wahlweise nach Häufigkeitsrang oder Menge der zugehörigen Types aufgelistet. Ein Klick auf einen Balken fügt die Normierung unten ein.



Hier können einzelne Normierungen im Zeitverlauf dargestellt sowie inkludierende Normierungsgruppen aufgelistet werden. Ein Klick auf einen Eintrag der Liste führt zu einer exakten Darstellung dieser Normierungsgruppen. Die Betrachtung kann anhand der Normierungen oder der zugrundeliegenden Token erfolgen. Über den Link zu dolnoserbski.de finden sich weitere Informationen zu den Einträgen.
Ein Klick in der Timeline zeigt die Token bis zum angeklickten Jahr in einer Textvarianten-Visualisierung (TRAViz). Das Jahr kann ebenfalls über den Slider geändert werden. Wird der Slider deaktiviert, werden die Varianten des gesamten Zeitraums dargestellt.
Über die Liste der Normierungsgruppen kann der Input für TRAViz ebenfalls ausgewählt werden.
