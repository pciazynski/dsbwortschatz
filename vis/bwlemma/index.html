Die Lemmata sind hier nach Häufigkeitsrang aufgelistet. Ein Klick auf einen Balken fügt das Lemma unten ein.

Minimum Häufigkeit


Hier können einzelne Lemma im Zeitverlauf dargestellt sowie inkludierende Lemmagruppen aufgelistet werden. Ein Klick auf einen Eintrag der Liste führt zu einer exakten Darstellung dieser Lemmagruppe. Die Betrachtung kann anhand der Lemmata oder der zugrundeliegenden Token erfolgen. Über den Link zu dolnoserbski.de finden sich weitere Informationen zu den Einträgen.
Ein Klick in der Timeline zeigt die Token bis zum angeklickten Jahr in einer Textvarianten-Visualisierung (TRAViz). Das Jahr kann ebenfals über den Slider geändert werden. Wird der Slider deaktiviert, werden die Varianten des gesamten Zeitraums dargestellt.
Über die Liste der Lemmagruppen kann der Input für TRAViz ebenfalls ausgewählt werden.
